## File website
- `index.html`: struktur halaman
- `style.css`: desain dan tata letak
- `script.js`: data profil dan tombol pergantian tema
- `foto-mahasiswa.jpg`: foto pribadi yang perlu kamu tambahkan sendiri

## Cara menambahkan foto
1. Siapkan foto pribadi yang ingin dipasang.
2. Letakkan foto dalam folder yang sama dengan `index.html`, `style.css`, dan `script.js`.
3. Ubah nama file foto menjadi persis `foto-mahasiswa.jpg`.
4. Buka ulang `index.html` di browser untuk memeriksa foto.
5. Saat mengunggah ke GitHub, unggah juga file `foto-mahasiswa.jpg`.

Jika foto belum ada, website tetap berjalan dan menampilkan kotak bertuliskan “TAMBAHKAN FOTO”.

## Sebelum dikumpulkan
- Jika sudah tahu kelas dan kelompok, ubah nilai `kelas` dan `kelompok` di `script.js`.
- Periksa website dengan membuka `index.html`.
- Buat repository GitHub bernama `praktikum1`.
- Unggah `index.html`, `style.css`, `script.js`, `README.md`, serta `foto-mahasiswa.jpg`.
- Klik **Commit changes**, lalu salin tautan repository ke Google Form dari dosen.

## Cara mengunggah ke GitHub
1. Login ke https://github.com/new
2. Nama repository: `praktikum1`.
3. Pilih **Public** jika dosen perlu mengakses repository.
4. Klik **Create repository**.
5. Pilih **Add file → Upload files**, lalu unggah file website.
6. Klik **Commit changes**.
